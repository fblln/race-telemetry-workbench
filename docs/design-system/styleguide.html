Design System

Carbon Signal

The visual language for the Race Telemetry Workbench — a dense, dark motorsport analysis surface. It trades the pure-black engineering look of legacy tools for a warm graphite base lit by a single signal amber accent, with an original, colorblind-safe channel palette so traces, flags, and the replay cursor never compete.

Base warm graphite #14110E Accent signal amber #FFA60D Channels Okabe-Ito derived Type Inter + JetBrains Mono

MCP · strategy_story

Race story — natural language (MCP)

The AI Assistant Panel (§8.10): the MCP server chains telemetry, stint, and event queries and an LLM composes a narrative briefing — not just charts. Tool calls are shown as quiet pills so the answer stays auditable.

Assistant
Where did LEC lose the place to HAM, and why?
LEC lost P2 to HAM around lap 32. From lap 28 his medium tyres dropped ~0.4 s/lap in sector 2 — the high-speed Ascari–Parabolica stretch — while HAM, two laps fresher, held pace. HAM closed into DRS on lap 31 and completed the move into Turn 1 on lap 32. Pitting LEC one lap earlier would have cleared the undercut but exposed him to the lap-22 VSC traffic.

Accessibility & principles

Density with legibility. This is a workbench: every panel describes the same replay timestamp. Color, dash redundancy, and tabular numerics let a user read six channels at a glance without the UI shouting.

Do

  • Reserve amber for one primary action, selection, focus, and the cursor.
  • Pair every channel hue with its dash pattern so lines survive grayscale.
  • Use mono tabular figures for all telemetry so columns never jump.
  • Encode delta sign with green/red and a leading + / − glyph.
  • Keep body text on surfaces above 7:1 contrast; ticks above 4.5:1.
  • Offer a reduced-motion mode that freezes non-essential transitions.

Don't

  • Paint telemetry traces amber — it collides with the cursor.
  • Rely on hue alone to separate driver A from driver B.
  • Animate the replay render loop with CSS transitions — it's real-time.
  • Use pure black surfaces; the warm graphite base is the brand.
  • Stack more than one amber primary button in a single view.
  • Interpolate weather like high-frequency data — show nearest/stepped.
